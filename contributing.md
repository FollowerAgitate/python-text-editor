## 🔧 Troubleshooting

| **Problem** | **Solution** |
|--------------|---------------|
| **PyQt6 import error** | Install with `pip install PyQt6` |
| **Fonts missing** | Install system fonts |
| **High DPI blurry** | Set `QT_ENABLE_HIGHDPI_SCALING` |
| **Plugin not loading** | Check plugin version |
| **Build fails** | Update PyInstaller |
| **Slow on large files** | Disable live highlight |
